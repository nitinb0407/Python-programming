# MODULE 4 - File Handling and CSV

- `lab1_log_file_reader.py`: reads `sample.log` and counts INFO, WARNING and ERROR entries.
- `lab2_student_data_manager.py`: adds and displays student records in `students.txt`.
- `lab3_csv_payroll_management.py`: reads `employees.csv` and calculates payroll.
- `sample_output.txt`: example output for all three labs.

## Run
Requires Python 3; no external packages.

```bash
python lab1_log_file_reader.py
python lab2_student_data_manager.py
python lab3_csv_payroll_management.py
```

Keep the sample input files in this folder.

## Payroll formula
Up to 40 hours are paid at the normal hourly rate. Hours above 40 are paid at 1.5 times the hourly rate. Gross pay is reduced by the deduction percentage to calculate net pay.
