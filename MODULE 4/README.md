# MODULE 4 – File Handling and CSV Programs

## Programs
1. **Lab1_Log_File_Reader.py** – Reads a log file and counts INFO, WARNING, and ERROR entries.
2. **Lab2_Student_Data_Manager.py** – Adds, displays, and searches student records stored in a text file.
3. **Lab3_CSV_Based_Payroll_Management_System.py** – Reads employee details from CSV, calculates payroll, and writes a payroll report.

## How to run
Open a terminal in this folder and run:

```bash
python Lab1_Log_File_Reader.py
python Lab2_Student_Data_Manager.py
python Lab3_CSV_Based_Payroll_Management_System.py
```

The programs use only Python's standard library. Sample output files are included for each lab. The log reader and payroll program create sample input files if those files do not exist. The student manager creates `students.txt` when the first student is added.
