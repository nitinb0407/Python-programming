# Module 2 - Python Programming

This folder contains four Python lab exercises focused on decision-making, loops, functions, recursion, and basic automation.

## Lab Exercises

1. **Lab 1 - Number Guessing Game:** Generates a random number from 1 to 100 and lets the user guess it with hints.
2. **Lab 2 - Prime Number and Factorial Programs:** Checks whether a number is prime and calculates the factorial of a non-negative number.
3. **Lab 3 - Fibonacci Series Using Recursion:** Generates Fibonacci numbers using a recursive function.
4. **Lab 4 - Student Grading Automation:** Accepts marks for three subjects and displays the total, average, grade, and result.

## How to Run

Open a terminal in this folder and run a program using:

```bash
python "Lab 1 - Number Guessing Game.py"
```

Replace the filename with the lab you want to execute.

See **Sample Output.txt** for example runs. These programs use only Python's built-in modules; no additional packages are required.
