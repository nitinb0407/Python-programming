# Module 2 - Python Programming

This folder contains four Python lab exercises covering loops, conditions, functions, recursion, and basic automation.

## Lab Programs

1. **Lab 1 - Number Guessing Game:** Uses Python's random module and a loop to let the user guess a randomly selected number.
2. **Lab 2 - Prime Number and Factorial:** Checks whether a number is prime and calculates its factorial.
3. **Lab 3 - Fibonacci Series Using Recursion:** Generates the Fibonacci series using a recursive function.
4. **Lab 4 - Student Grading Automation:** Accepts subject marks, calculates the total and average, and displays a grade.

## How to Run

Open a terminal in this folder and run a program like this:

```bash
python "Lab 1 - Number Guessing Game.py"
```

Replace the filename with the lab you want to execute.

See **Sample Output.txt** for example runs. These programs use Python's built-in modules only; no additional packages are required.
