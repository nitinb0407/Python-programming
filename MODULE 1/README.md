# MODULE 1 - Python Programming

This folder contains the programs for Module 1 lab exercises and mini project.

## Lab Exercises

### Lab Exercise 1 - Basic Python Program
- `lab_exercise_1_basic_python.py`
- Covers basic output using `print()` and simple input using `input()`.

### Lab Exercise 2 - Variables, Operators and Input/Output
- `lab_exercise_2_variables_operators_io.py`
- Covers variables, input/output, arithmetic operators, comparison operators and logical operators.

### Lab Exercise 3 - Simple Calculator and Area Calculation
- `lab_exercise_3_simple_calculator.py`
- `area_calculator.py`
- Covers arithmetic calculations, conditional statements and area formulas for common shapes.

## Mini Project

### Unit Converter
- `mini_project_unit_converter.py`
- Converts:
  - Kilometers ↔ Miles
  - Celsius ↔ Fahrenheit
  - Kilograms ↔ Pounds
  - Meters ↔ Feet

## How to Run

Open a terminal in the repository and run any file with:

```bash
python "MODULE 1/filename.py"
```

Example:

```bash
python "MODULE 1/mini_project_unit_converter.py"
```
