# MODULE 2 - Python Programming

This folder contains the programs for the Module 2 lab practice and mini project.

## Lab Exercise 1 - Number Guessing Game
- `lab_exercise_1_number_guessing_game.py`
- Uses the `random` module, loops, conditions and user input.
- The computer selects a number from 1 to 100 and the user keeps guessing until the correct number is found.

## Lab Exercise 2 - Prime Number and Factorial
- `lab_exercise_2_prime_number.py`
- Checks whether a given number is prime.
- `lab_exercise_2_factorial.py`
- Calculates the factorial of a non-negative integer using a loop.

## Lab Exercise 3 - Fibonacci Using Recursion
- `lab_exercise_3_fibonacci_recursion.py`
- Generates the Fibonacci series using a recursive function.

## Mini Project - Student Grading Automation
- `mini_project_student_grading.py`
- Accepts marks for five subjects.
- Calculates total and average marks.
- Automatically assigns a grade and displays Pass/Fail status.

## How to Run

From the repository folder, run any program using:

```bash
python "MODULE 2/filename.py"
```

Example:

```bash
python "MODULE 2/mini_project_student_grading.py"
```
