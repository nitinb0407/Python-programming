# Module V - Python Lab Programs

This folder contains four Python lab programs.

## Lab Programs

1. **Lab 1 - Bank Account System using OOP**  
   Demonstrates classes, objects, deposit, withdrawal, and balance checking.

2. **Lab 2 - Library Management System**  
   Demonstrates adding, displaying, borrowing, and returning books.

3. **Lab 3 - Dice Simulator using Random Module**  
   Uses Python's `random` module to simulate dice rolls and count results.

4. **Lab 4 - Retail Sales Dashboard using CSV and Matplotlib**  
   Reads sales records from a CSV file, calculates product-wise and total sales, and generates a bar chart.

## Files

- Each lab has its own Python file.
- `sales_data.csv` contains the sample sales records used in Lab 4.
- `Sample Output.txt` contains example console outputs for all four labs.

## How to Run

Open a terminal in this folder and run the required program. For example:

```bash
python "Lab 1 - Bank Account System using OOP.py"
```

For Lab 4, install Matplotlib first:

```bash
pip install matplotlib
```

Then run:

```bash
python "Lab 4 - Retail Sales Dashboard using CSV and Matplotlib.py"
```

The Lab 4 program reads `sales_data.csv` from the current working directory and saves the chart as `retail_sales_dashboard.png`.

The sample outputs are illustrative. Interactive inputs and random dice results may differ when you run the programs.
