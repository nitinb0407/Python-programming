MODULE 5 - LAB EXERCISE 4
Retail Sales Dashboard Using CSV and Matplotlib

OBJECTIVE
To read retail sales data from a CSV file and visualize the data using line graphs and bar charts.

SAMPLE INPUT (sales.csv)
Product,Sales
Pen,1200
Book,2500
Bag,4000

SAMPLE CONSOLE OUTPUT
RETAIL SALES REPORT
-------------------
Pen: Rs. 1200.00
Book: Rs. 2500.00
Bag: Rs. 4000.00
-------------------
Total Sales: Rs. 7700.00
Average Sales: Rs. 2566.67

GRAPH OUTPUT
1. A line graph showing sales for Pen, Book and Bag.
2. A bar chart comparing sales for Pen, Book and Bag.

NOTE
Install Matplotlib using:
python -m pip install matplotlib

Keep sales.csv in the same folder as the Python program.
