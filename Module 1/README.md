# Module 1 - Python Programming

This folder contains four beginner-level Python lab programs.

## Lab Programs

1. **Lab 1 - Basic Python Program:** Displays simple messages using print().
2. **Lab 2 - Variables, Operators and Input/Output:** Accepts user details and numbers, then performs arithmetic operations.
3. **Lab 3 - Simple Calculator and Area Calculator:** Performs basic calculations and calculates the area of a rectangle or circle.
4. **Lab 4 - Unit Converter and Bill Generator:** Converts kilometres to miles or Celsius to Fahrenheit and generates a simple item bill.

## How to Run

Open a terminal in this folder and run any program using:

```bash
python "Lab 1 - Basic Python Program.py"
```

Replace the filename with the lab you want to execute.

See **Sample Output.txt** for example runs. The programs use only Python's built-in features; no additional packages are required.
